# ملاحظات المالك للتحديث القادم

تاريخ التسجيل: 2026-10-23

## التحكم بإيقاف فيديو المتصفح أثناء الحركة

طلب المالك أن يتحكم مفتاح الإعدادات في سلوك فيديو المتصفح على شاشة السيارة كما يصف سلوك النسخة السابقة:

- عند تفعيل المفتاح: تُراقب الحركة عبر GPS، وعند الحركة يتوقف عرض الفيديو ويستمر الصوت حيث تدعم آلية التشغيل ذلك.
- عند إلغاء تفعيل المفتاح: طلب المالك استمرار عرض فيديو المتصفح حتى أثناء حركة السيارة.
- موقع المفتاح المطلوب: الإعدادات ← إعدادات المشغّل ← أسفل الصفحة.

الحالة: طلب مسجّل للتحديث القادم، ولم يُنفّذ تغيير سلوك القفل. تسجيل الطلب لا يُعد إثباتاً لتوافقه مع قيود المنصة أو اعتماداً لتنفيذه. لا توجد تغييرات برمجية أو بناء أو رفع ناتجة عن تسجيل هذه الملاحظة.
