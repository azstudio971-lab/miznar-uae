## Limits / acceptance still pending
- Physical vehicle testing is owner-only and not claimed.
- CarPlay mini player allowsMiniPlayer requires a newer SDK than current runner; conditionally compiled under WUDCAR_IOS27_SDK. Now Playing and Up Next exist on current SDK.
- Rate control is phone-only; official CarPlay rate button is present but disabled, per requested phone-only rates.
- Frozen legacy browser pauses ALL web media under movement lock. Continuing web audio cannot be promised without modifying frozen browser files.
- External SRT/VTT overlay is iPhone-only; external screens and PiP use source-embedded subtitles.
- Actual CarPlay screenshots require a real CarPlay Simulator session and are not fabricated. Native phone view captures are generated by XCTest at requested pixel dimensions; review visual quality before using them as store assets.
- Retaining both entitlements and the legacy external browser does not establish Apple approval. Review notes acknowledge the prior 2.5.1 guidance.
