## التنفيذ
- الرئيسية ← الترفيه ← الإعدادات، في قوالب CarPlay ونافذة السيارة الخارجية.
- الترحيب والتعليمات بالعربية والإنجليزية، مع الشعار الأصلي.
- إنشاء المتصفح عند اختيار الترفيه، والاحتفاظ بجلساته عند التنقل. بقيت اختصاراته وتبويباته والرجوع والمفضلة. Xtream متاح من قائمة الترفيه الرسمية ومن تطبيق الهاتف.
- إعدادات محفوظة للغة، سطح المكتب/الهاتف، ونسبة الصفحة 50–150% بخطوات 5% وإعادة إلى 100%.
- إطار WKWebView مثبت بكامل المساحة. نسبة المحتوى عبر pageZoom، وعرض المستند يعاد توزيعه وفق visualViewport بدلاً من تصغير إطار WebView.
- تفضيل WebKit لسطح المكتب ووكيل مستخدم سطح المكتب، مع طلب YouTube desktop والحفاظ على بقية معاملات الرابط ومعالجة تحويل الهاتف مرة واحدة لمنع حلقات التحويل.
- زر توسعة واضح في زاوية الفيديو المتاح، مع الحفاظ على زر الشريط وإمكانية العودة ونسبة الأبعاد الافتراضية contain.
