# WudCar — انترو تشغيل الآيفون

اعتمد صاحب التطبيق هذين الفيديوهين بتاريخ 14 أكتوبر 2026 للاستخدام عند تطوير الإصدار المرجعي V2. اسم التطبيق يبقى WudCar.

- `WudCar-Intro-Light.mp4`: للوضع النهاري (Light).
- `WudCar-Intro-Dark.mp4`: للوضع الليلي (Dark).
- يظهر الفيديو المناسب لمظهر التطبيق مرة واحدة عند بدء تشغيل تطبيق الآيفون، ثم ينتقل إلى الواجهة الرئيسية؛ لا يتكرر ولا يُستخدم كخلفية.
- مخصص للآيفون فقط؛ لا يظهر على CarPlay.
- كل فيديو مدته 6 ثوانٍ، بدقة رأسية 512×910، بتنسيق MP4 مع H.264 وAAC.
- تم حفظ الملفات الأصلية دون تحويل أو ضغط إضافي، مع تغيير أسماء الملفات لتسهيل استخدامها في البرمجة.
- هذه أصول محفوظة للتطوير لاحقًا؛ تشغيل الانترو وربطه بمشروع Xcode لم يُنفّذ بعد.

`manifest.json` يوثق اختيار المظهر وحجم الملفات وبصمات SHA-256.
