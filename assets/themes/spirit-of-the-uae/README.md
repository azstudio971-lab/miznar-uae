# Spirit of the UAE — روح الإمارات

الثيم الافتراضي المرئي لتطبيق WudCar — وُد كار، رفيق مشاويرك.

## الملفات
- ultrawide: أربع صور PNG بمقاس 2172 × 724، بنسبة 3:1، مع امتداد جانبي.
- compact: أربع صور PNG بمقاس 1402 × 1122، بنسبة تقارب 5:4 للشاشات الأقرب للمربع.
- كل مجموعة: dawn / morning / sunset / night.
- المشهد نفسه عبر الأوقات، مع تغييرات إضاءة مولدة؛ قد توجد فروق دقيقة بين النسخ.
- منظر فني تخيلي مستوحى من صحراء الإمارات وأفق دبي، وليس تصويرًا لموقع جغرافي حقيقي.
- الصور بلا ساعة أو نص أو أزرار. أعلى اليمين خافت ومخصص لإضافة الساعة والودجت.

## التنفيذ لاحقًا
theme.json يحدد الثيم الافتراضي والملفات. لا يحتوي المشروع هنا على تطبيق أو كود لتبديل الثيم.
قياس مساحة العرض الفعلية بعد safe area؛ اختيار ultrawide عند نسبة >= 1.9، وإلا compact، نقطة بداية للاختبار.
استخدام aspect-fill دون تمديد أو تشويه. مراجعة القص ومكان الساعة لكل نسبة، خاصة الشاشات الرأسية.
هذه أصول مرنة وليست ضمانًا بالتوافق مع جميع السيارات. المقاسان ليسا قياسات معتمدة لطراز سيارة بعينه.
توقيت الفجر والصباح والمغرب والليل سيُضبط في لوحة التحكم لاحقًا؛ لا نعتمد مواعيد ثابتة للمغرب طوال العام.
واجهة خلفية مخصصة داخل CarPlay تتطلب التحقق من فئة التطبيق وصلاحياته وقوالب Apple قبل تنفيذها.
